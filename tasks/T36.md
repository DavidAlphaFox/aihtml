# T36 · ai_jinja_scanner —— 定界符与空白控制

- **阶段**：9
- **依赖**：[T35](T35.md)
- **状态**：已完成

## 目标

单遍扫描模板正文，切出 text / expr / stmt token，处理注释、`{% raw %}` 与全套空白控制规则。

## 交付物

- `src/ai_jinja_scanner.erl`
- `test/ai_jinja_scanner_tests.erl`

## 实现要点

### 1. 接口

```erlang
-spec scan(unicode:chardata(), map()) ->
        {ok, [jinja_token()]} | ai_html_error(ai_jinja_reason()).
```

入口做一次 `ai_html_text:template/1`：非法 UTF-8 直接拒绝，报
`{invalid_utf8, ByteOffset}`。此后所有内部处理只见 binary
（[02 §7](../designs/02-architecture.md)）。

### 2. 扫描顺序

遇到 `{` 看下一字节，**`{#` 必须最先判**（[09 §1.1](../designs/09-jinja-syntax.md)）：
注释里可以合法地包含未闭合的 `{%`。

### 3. 结束符查找必须跳过字符串字面量

`{{ a|replace("%}", "x") }}` 里的 `%}` 不是结束符。
因此 expr / stmt 的体不能用 `binary:match/2` 找结束符，必须委托
`ai_jinja_lexer:tokens/3`（[T37](T37.md)）边词法分析边推进，由 lexer 在
**括号深度为 0** 时遇到结束符停下并返回消费字节数。

注释体反之：注释里没有字符串字面量的概念，`binary:match/2` 找 `#}` 即可。

**这条决定了 T36 与 T37 有循环依赖**。解法：scanner 调用 lexer，lexer 不调用 scanner；
先实现 lexer 的骨架（哪怕只支持字符串与括号计数），再实现 scanner。
两个任务的测试可以互相独立。

### 4. `{% raw %}`

scanner 层直接吃掉，产出一个 `{raw, Loc, Body}` token，parser 不需要知道它存在。
`{% endraw %}` 的查找是纯字节匹配，raw 体内的一切都不解析。
`{% raw %}` 内出现 `{% raw %}` **不嵌套**（Jinja2 亦然），第一个 `{% endraw %}` 即结束。

### 5. 空白控制

严格按 [09 §2](../designs/09-jinja-syntax.md)，三步顺序固定：

```
1. lstrip_blocks   左侧行首空白（只对 {% 与 {#，不对 {{）
2. 显式 - / +      覆盖 1 与 3
3. trim_blocks     右侧紧跟的一个换行（只对 %} 与 #}，不对 }}）
```

**`{{-` 的裁剪不限行数**：`a\n\n\n   {{- x }}` → `ax`。这与直觉不同，要有专门用例。

`keep_trailing_newline=false`（默认）在扫描**开始前**对整个正文做一次预处理，
删掉末尾的一个 `\n`（只删一个，且只在正文以 `\n` 结尾时）。

### 6. 裁剪只作用于 text token

绝不作用于插值的输出（[09 §2.4](../designs/09-jinja-syntax.md)）。
`{{- x -}}` 裁的是两侧静态文本，`x` 的值自带的前后空白原样保留。
这类 bug 只在「值本身以空白开头」时暴露，要有针对性用例。

### 7. 位置信息

每个 token 带 `{Line, Col}`。换行计数在 text 与 tag 体内都要正确推进，
否则一个多行 `{% for %}` 之后的所有行号都会偏。

## 验收标准

- [ ] `scan/2` 覆盖 text / `{{ }}` / `{% %}` / `{# #}` / `{% raw %}` 五种形态
- [ ] 注释里含 `{%`、`{{`、未闭合结构时不报错，整体丢弃
- [ ] `{{ a|replace("%}", "x") }}` 正确扫描（结束符在字符串内被跳过）
- [ ] `{{ {"a": 1} }}` 正确扫描（括号深度）
- [ ] 空白控制的组合矩阵全通过：`-`/`+`/无 × `trim_blocks` × `lstrip_blocks`，两侧独立
- [ ] `{{-` 跨多个空行裁剪
- [ ] `keep_trailing_newline` 两种取值的行为正确，且只删一个 `\n`
- [ ] 裁剪不影响插值输出（专项用例）
- [ ] 多行 tag 之后的行号正确
- [ ] 非法 UTF-8 报 `{invalid_utf8, Offset}` 且 Offset 指向真实位置
- [ ] 未闭合的 `{{` / `{%` / `{#` / `{% raw %}` 各有明确诊断
- [ ] fixture 中 `whitespace` 与 `lexer` 组用例点亮
