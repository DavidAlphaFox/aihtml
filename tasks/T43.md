## 目标

## 交付物

- `src/ai_jinja_filters.erl`
- `test/ai_jinja_filters_tests.erl`

## 实现要点

### 1. 统一签名

```erlang
-spec upper(term(), map()) -> term().
upper(V, _Args) -> ...
```

第二参数是**关键字参数 map**，位置参数由 compiler 按各 filter 的参数名映射进去。
每个 filter 在 module doc 的表里声明自己的位置参数名，compiler 读这张表 ——
**声明与实现放在同一个模块**，不会漂移。

```erlang
-spec params() -> #{atom() => [atom()]}.
params() -> #{join => [d, attribute], replace => [old, new, count], ...}.
```

### 2. 清单（[10 §8.2](../designs/10-jinja-semantics.md)）

**字符串** `upper lower capitalize title trim striptags truncate wordwrap
wordcount center indent replace format urlencode urlize escape e forceescape safe string`

**序列** `first last length count list join reverse sort sum min max unique
slice batch groupby map select reject selectattr rejectattr random`

**映射** `dictsort items attr tojson`

**数值** `abs round int float filesizeformat`

**通用** `default d pprint`

### 3. 每个 filter 的三件事

1. **`@safe` 标注**（[T42](T42.md)）
2. **`undefined` 输入的行为**：绝大多数返回 `undefined` 或空值，**不抛异常**。
   例外是 `length` / `first` / `last` 对 `undefined` 返回 `undefined` 而非报错。
   `default` 是唯一把 `undefined` 转成别的值的 filter。
3. **边界用例**：空列表、空字符串、单元素、类型不符。

### 4. 几个容易做错的

- **`sort`**：默认按 Erlang 项序，`reverse=true`、`attribute="x"`、`case_sensitive=false`
  三个关键字参数。`case_sensitive=false` 是默认值（与 Python 一致）。
- **`round`**：`precision` 与 `method`（`common`/`ceil`/`floor`）。
  `common` 走的是 Python 的 `round/2`，也就是**向偶数舍入**（banker's rounding）：
  `0.5|round` 是 `0.0` 而不是 `1.0`。这一条以 fixture 为准，
  不要按「四舍五入」的直觉实现。返回值始终是 float。
- **`join`**：`d` 分隔符 + `attribute`。对非 safe 元素先转义（escaping 类）。
- **`tojson`**：用 OTP 的 `json:encode/1`（零依赖）。输出必须对 `<` `>` `&` `'`
  做 `\uXXXX` 转义，否则嵌在 `<script>` 里是 XSS。**这是 generating 类里最危险的一个。**
- **`urlencode`**：map 输入产出 query string，binary 输入产出 percent-encoding。
- **`filesizeformat`**：`binary=true` 时用 1024 进制。
- **`groupby`** / **`selectattr`** / **`rejectattr`**：可裁剪项（[13 §5](../designs/13-jinja-roadmap.md)）。
- **`map`/`select`/`reject`**：参数是 filter/test **名字的字符串**，
  走 `ai_jinja_rt:apply_named/3` 的**白名单派发**，白名单只含内置与已注册模块，
  不接受任意 atom（[10 §8.2](../designs/10-jinja-semantics.md)）。
- **`random`**：需要随机数，用 `rand` 模块。**这让它不是纯函数** ——
  在 module doc 里点明，且它是唯一一个。

### 5. 未知 filter 是编译期错误

不在本模块处理 —— compiler 在编译期查表，查不到报 `{unknown_filter, Name, Loc}`
（[10 §8.1](../designs/10-jinja-semantics.md)）。本模块只需导出一张
`filters() -> #{atom() => arity()}` 供 compiler 查。
