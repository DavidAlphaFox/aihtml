# T37 · ai_jinja_lexer —— 表达式词法

- **阶段**：9
- **依赖**：[T35](T35.md)
- **状态**：已完成

## 目标

把 `{{ }}` / `{% %}` 体内的字节流切成表达式 token，并告诉 scanner 在哪里结束。

## 交付物

- `src/ai_jinja_lexer.erl`
- `test/ai_jinja_lexer_tests.erl`

## 实现要点

### 1. 接口（流式）

```erlang
-spec tokens(binary(), ai_html_loc(), Stop :: expr_end | stmt_end) ->
        {ok, [jinja_expr_token()], Rest :: binary(), ai_html_loc()}
      | ai_html_error(ai_jinja_reason()).
```

`Stop` 决定认哪个结束符（`}}` 还是 `%}`）。**只有在括号深度为 0 时**遇到结束符才停。
返回的 `Rest` 是结束符之后的剩余正文，scanner 据此继续。

结束符前的 `-` / `+`（`-}}` / `-%}` / `+%}`）由 lexer 识别并作为返回值的一部分
告知 scanner，不作为运算符 token 吐出。

### 2. token 清单

按 [09 §3.1](../designs/09-jinja-syntax.md)：

- **数字**：`123` · `1_000` · `0x1f` · `0o17` · `0b1010` · `1.5` · `1e10` · `1.5e-3` · `1_000.5`
  下划线分隔符要在转换前剔除。
- **字符串**：`"..."` / `'...'`，转义 `\n \t \r \\ \" \' \xHH \uHHHH`。
  `\uHHHH` 产出 UTF-8 编码的字节。未知转义序列**保留反斜杠**（Python 行为）。
- **相邻字符串拼接**在 lexer 层做还是 parser 层做？**parser 层**（[09 §3.3](../designs/09-jinja-syntax.md)
  的 `primary = ... | STRING+`），lexer 只管产出独立 token。
- **名字**：`[A-Za-z_][A-Za-z0-9_]*`。**只支持 ASCII**（[10 §9](../designs/10-jinja-semantics.md) J10）。
  遇到非 ASCII 标识符字符报 `{unexpected_token, ...}` 而非静默截断。
- **关键字**：`and or not in is if else true True false False none None`
  作为独立 token 类型吐出，parser 不需要再比对字符串。
- **运算符**：按最长匹配。`**` 先于 `*`，`//` 先于 `/`，`==` 先于 `=`，
  `<=` `>=` `!=` 先于 `<` `>`。**漏了任何一条最长匹配都会产生难查的解析错误。**

### 3. 括号深度

`(` `[` `{` 加一，`)` `]` `}` 减一。深度为负立即报错
（`{{ a) }}`），不要等到 parser。

`{{ {"a": 1} }}`：中间的 `}` 让深度归零，紧接着的 ` }}` 才是结束符。
这个用例必须有。

### 4. 位置

每个 token 带 `{Line, Col}`，Col 从 1 开始。多行表达式内的换行要推进 Line。
这是 [09 §6](../designs/09-jinja-syntax.md) 精确错误定位的基础。

### 5. 不做的事

lexer 不做任何语法判断：`{{ + }}` 在 lexer 层是合法的（一个 `+` token），
由 parser 报错。职责分离让两边的测试都能独立写。

## 验收标准

- [ ] 数字的六种进制/形态全部正确，含下划线分隔符
- [ ] 字符串的全部转义序列正确；未知转义保留反斜杠；未闭合字符串有明确诊断
- [ ] 运算符最长匹配：`**` `//` `==` `!=` `<=` `>=` 各有用例，且与单字符版本的组合（`a**-b`、`a//-b`）正确
- [ ] 括号深度为 0 时才认结束符；`{{ {"a": 1} }}` 正确
- [ ] 深度为负立即报错
- [ ] `-}}` / `-%}` / `+%}` 作为空白标记返回，不作为运算符 token
- [ ] 非 ASCII 标识符报错而非静默处理
- [ ] 每个 token 的 `{Line, Col}` 正确，含多行表达式
- [ ] fixture 中 `lexer` 组用例点亮
