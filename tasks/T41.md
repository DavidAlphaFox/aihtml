## 实现要点

### 1. 作用域

```erlang
-type scope() :: [map()].

resolve(Name, Scope)          -> term().          % 栈顶向外找第一个含该名的 map frame
bind(Scope, Name, Val)        -> scope().         % 替换栈顶 frame
bind2(Scope, N1, V1, N2, V2)  -> scope().         % for 循环的高频路径，省一次 map 构造
push(Scope, Frame :: map())   -> scope().
root(Scope)                   -> term().          % 栈底，{% include without context %} 用
```

`bind/3` 是**替换栈顶 frame**（`[maps:put(N,V,Top) | Rest]`），不是 push。
push 会让作用域链无限增长，而 `{% set %}` 在语义上就是改当前帧。

栈底可以是非 map 的裸值（与 mustache 一致），`resolve/2` 跳过非 map frame。

**不要复用 `ai_mustache_rt:lookup/2`**：形状相似但含义不同
（[10 §2.2](../designs/10-jinja-semantics.md)）。

### 2. 真值

按 [10 §5](../designs/10-jinja-semantics.md)。**与 mustache 不同**：
`0` `0.0` `#{}` `{}` 都是假。写成独立子句让 BEAM 生成跳转表。

### 3. 属性与下标

```erlang
attr(M, K) when is_map(M) -> maps:get(K, M, undefined);
attr({ns, M}, K)          -> maps:get(K, M, undefined);
attr(undefined, _)        -> undefined;            % 可链式
attr(_, _)                -> undefined.

subscript(L, I) when is_list(L), is_integer(I) -> nth 或 undefined（支持负索引）
subscript(M, K) when is_map(M) -> ...
subscript(B, I) when is_binary(B), is_integer(I) -> 第 I 个字符（UTF-8 感知）
```

**字符串下标的 key 转换**：`{{ d["a"] }}` 运行期拿到 binary key 时用
`binary_to_existing_atom/2`，失败即 `undefined`。
**绝不用 `binary_to_atom/2`** —— 那是把模板数据变成 atom 表攻击面
（[10 §1](../designs/10-jinja-semantics.md)）。

`.items()` / `.keys()` / `.values()` 三个特例在 compiler 层识别成
`ai_jinja_rt:items/1` 等，不走 `attr/2`。

### 4. 运算符

`add/2` `sub/2` `mul/2` `divide/2` `floordiv/2` `mod/2` `pow/2` `concat/2`
`eq/2` `ne/2` `lt/2` `le/2` `gt/2` `ge/2` `contains/2`。

要点（[11 §3.3](../designs/11-jinja-codegen.md)）：

- **`add/2` 对两个 binary 是拼接**（Python 语义），对 list 是 `++`，对数值是加。
  混合类型（binary + integer）→ 抛 `{ai_jinja, {unsupported_operands, '+', A, B}}`。
- `divide/2` 是真除：`1/2` = `0.5`。除零抛 `{ai_jinja, division_by_zero}`。
- `floordiv/2` 是向下取整除；`mod/2` 是**取模**不是 `rem`：`-7 mod 3` = `2`。
- `pow/2` 对整数指数用 `trunc(math:pow/2)` 会丢精度，大整数要走自己的快速幂。
- `concat/2`（`~`）无条件把两侧 `to_binary/1` 后拼接。
- 比较：数值跨类型可比（`1 == 1.0` 为真），binary 与 binary 按字节序，
  其它类型不可比时 `eq/ne` 返回结果、`lt/le/gt/ge` 抛错。
- 任一操作数是 `undefined` → 抛 `{ai_jinja, {undefined_operation, Op}}`
  （[10 §3](../designs/10-jinja-semantics.md)）。

**每个运算符都要有异常路径的用例。** 这是最容易只测 happy path 的一块。

### 5. 迭代与 `loop`

```erlang
to_list(L) when is_list(L)  -> L;
to_list(M) when is_map(M)   -> maps:keys(M);        % 与 Python dict 一致
to_list(T) when is_tuple(T) -> tuple_to_list(T);
to_list(undefined)          -> [];
to_list(B) when is_binary(B) -> error({ai_jinja, {not_iterable, B}});   % 见 10 §6
to_list(V)                  -> error({ai_jinja, {not_iterable, V}}).

loop(Index1, Len, Item, All) -> map().   % 构造 loop 变量
```

`loop` 字段全集：`index index0 revindex revindex0 first last length
cycle depth depth0 previtem nextitem changed`。
`cycle` 与 `changed` 是函数字段（`fun/1`），其余是值。

`previtem` / `nextitem` 在首尾分别为 `undefined`。

### 6. 调用派发

```erlang
call(F, Pos, Kw) when is_function(F) -> ...
call(V, _, _) -> error({ai_jinja, {not_callable, V}}).
```

按 arity 尝试：优先 `F(Pos ++ [Kw])` 的约定形态，具体约定在 module doc 写死。

### 7. 内置函数

`range/1,2,3` `dict/1` `namespace/1`。

`cycler` / `joiner` / `lipsum` **不实现**：前两个在参照实现里是有状态对象，
每次调用都要推进内部游标，而本模块不得持有任何状态（[架构不变量 #1](../designs/02-architecture.md)）。
`loop.cycle(...)` 覆盖了 `cycler` 的绝大多数用法，且它是无状态的——按 `loop.index0` 取模。
`namespace/1` 返回 `{ns, map()}`（[10 §2.5](../designs/10-jinja-semantics.md)）。

### 8. 零依赖与无状态

无进程、无 ets、无 persistent_term、无进程字典
（[02 §8](../designs/02-architecture.md) 不变量 1）。
只依赖 OTP 与 `ai_html_escape`。

## 验收标准

- [ ] 作用域五个函数各有用例；`bind/3` 替换栈顶而非 push（栈深度不随 set 增长，有断言）

- [ ] 字符串下标走 `binary_to_existing_atom/2`；源码 grep 不到 `binary_to_atom(`
- [ ] 15 个运算符各有正常路径与异常路径用例
- [ ] `-7 mod 3` = `2`（取模不是 rem）；`1/2` = `0.5`；`1 == 1.0` 为真

- [ ] 迭代 binary 报 `{not_iterable, _}`；迭代 `undefined` 得空列表

- [ ] `cycler` / `joiner` / `lipsum` 不在内置表中，且文档写明原因
- [ ] 无进程/ets/persistent_term/进程字典（代码审查 + grep）
