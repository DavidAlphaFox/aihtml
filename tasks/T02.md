# T02 · 旧实现移出构建路径

- **阶段**：1
- **依赖**：T01
- **状态**：已完成

## 目标

把依赖 ailib 的旧实现移出 `src/`，让新构建能跑通；同时保留代码供阶段 2 重写 scanner/parser 时参考，阶段 6 再彻底删除。

## 交付物

- `attic/` —— 旧实现暂存目录，不在构建路径内
- `attic/README.md` —— 说明该目录的用途与删除时机

## 实现要点

### 移动清单

以下文件从 `src/` 移到 `attic/`：

| 文件 | 移动理由 |
|---|---|
| `ai_mustache.erl` | 门面要重写（进程字典缓存去掉，API 换成 `render/2` + `render_iolist/2` + `inline/2`） |
| `ai_mustache_loader.erl` | ets + gen_server 缓存机制被编译期方案取代 |
| `ai_mustache_parser.erl` | **重写时的主要参考**，`split_tag/2` 与 `standalone/3` 的逻辑要移植到新 scanner |
| `ai_mustache_runner.erl` | 解释器被生成代码取代 |
| `aihtml_app.erl` | 退化为 library app |
| `aihtml_sup.erl` | 无进程可管 |
| `ai_dom_node.erl` | 与 mustache 无关（决策 D4） |
| `ai_dom_render.erl` | 同上，且 `render/2` 有必崩 bug（B2） |

移动后 `src/` 只剩 `aihtml.app.src`。

`examples/dom_render.erl` 一并移入 `attic/`（它只用 `ai_dom_*`）。`examples/complex.erl` 与 `examples/*.mustache` **留在原地**，由 T28 按新语义重写。

### attic/README.md 内容要点

- 本目录是 v0.3.7 旧实现的暂存，**不在任何构建路径内**
- 保留原因：`ai_mustache_parser.erl` 的 `split_tag/2`、`standalone/3`、`repeatedly_binary/2`、`part/3` 是经过实战验证的 bbmustache 逻辑，阶段 2（T07/T08）重写 scanner 时需要逐段对照移植
- 保留原始 MIT 版权头（bbmustache, Hinagiku Soranoba）
- 删除时机：T26

### 注意事项

- 用 `git mv` 保留文件历史（但**不要 commit**）
- 移动后确认 `rebar3 compile` 仍能成功（此时 `src/` 只有 app.src，编译产出空模块列表是正常的）
- `attic/` 不要加进 `.gitignore` —— 它是要进版本库的临时目录，T26 时正式删除
