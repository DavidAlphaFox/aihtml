# T11 · ai_mustache_rt 值处理

- **阶段**：3
- **依赖**：[T01](T01.md)
- **状态**：已完成

## 目标

实现生成代码的运行期值处理三件套 `lookup/2`、`to_binary/1`、`truthy/1`，落地标准 mustache 的 context stack 语义与 spec 要求的数值格式化，且只依赖 OTP。

## 交付物

- `src/ai_mustache_rt.erl` —— 本任务负责 `lookup/2`、`to_binary/1`、`truthy/1` 三个导出（`escape/1`、`section/4`、`lambda/2` 见 [T12](T12.md)）

## 实现要点

### 0. 零依赖是硬约束

决策 D5：**彻底移除 ailib**（[designs/02-architecture.md §6](../designs/02-architecture.md)）。`ai_mustache_rt` 是生成代码的唯一运行期依赖，**它自己只能依赖 OTP**（[架构不变量 #3](../designs/02-architecture.md)）。

被替换的三个 ailib 函数：

| 原用途 | 替代 | 说明 |
|---|---|---|
| `ai_maps:get/3` | `lookup/2` | 语义本就不同：需要 context stack 回溯，无法复用 |
| `ai_string:to_string/1` | `to_binary/1` | 需按 spec 处理数值格式 |
| `ai_function:while/2` | 直接递归 | scanner 侧，见 [T07](T07.md) |

模块整体目标不足 200 行。

### 1. `lookup/2` —— context stack 回溯

```erlang
-spec lookup(ai_mustache_keys(), Stack :: [term()]) -> term().
```

规则来自 [designs/03-semantics.md §2](../designs/03-semantics.md)：

- **首段回溯**：`[K | Rest]` 中的 `K` 从栈顶向外逐层找，返回**第一个含 `K` 的 frame** 中的值。
- **后续段严格下钻**：拿到首段的值后，`Rest` 只在该值内部逐级取，**不回溯**。任一级取不到 → `undefined`。这是 `{{a.b}}` 的语义：`a` 可回溯，`b` 只在 `a` 里找。
- **首段找不到** → `undefined`。

骨架（对齐 [designs/04-codegen.md §5](../designs/04-codegen.md)）：

```erlang
lookup([?AI_MUSTACHE_DOT], [Top | _]) -> Top;      %% {{.}} 隐式迭代器
lookup([?AI_MUSTACHE_DOT], [])        -> undefined;
lookup([K | Rest], Stack) ->
    case find_frame(K, Stack) of
        {ok, V} -> descend(Rest, V);
        error   -> undefined
    end;
lookup([], [Top | _]) -> Top;
lookup([], [])        -> undefined.
```

**`{{.}}` 的处理必须在最前面**（模式匹配顺序），这是修 [B5](../designs/01-current-state.md) 的落点：旧实现把 `['.']` 当普通 key 去 map 里找，永远取不到。

`find_frame/2`：

```erlang
find_frame(_K, [])          -> error;
find_frame(K, [F | Rest]) when is_map(F) ->
    case F of
        #{K := V} -> {ok, V};
        _         -> find_frame(K, Rest)
    end;
find_frame(K, [_NonMap | Rest]) -> find_frame(K, Rest).
```

用 `#{K := V}` 而非 `maps:get/3`：单次匹配，且 `K` 是变量时 OTP 会走 `maps:find/2` 的等价路径，没有 `undefined` 默认值的歧义（value 本身可能就是 `undefined`）。

**非 map frame 必须跳过而不是崩**：栈里可能有 binary、integer、list（section 压栈时压的是元素本身，见 [designs/03-semantics.md §3](../designs/03-semantics.md) 的「其它（binary / number / atom）」行）。

`descend/2`：

```erlang
descend([], V) -> V;
descend([K | Rest], M) when is_map(M) ->
    case M of
        #{K := V} -> descend(Rest, V);
        _         -> undefined
    end;
descend(_, _) -> undefined.
```

**key 类型是 atom**（沿袭 v0.3.5 的决定，[designs/03-semantics.md §8](../designs/03-semantics.md) 的 known deviation）。spec 的 JSON 用 string key，测试 harness 负责 binary key → atom 转换（阶段 1 的 `ai_mustache_test_lib`）。`lookup/2` 本身**不做**双类型兜底（不要既试 atom 又试 binary）—— 那会让热路径上每次 miss 都做两次查找。

### 2. 根 context 可以是非 map 的裸值

spec 的 `interpolation.json` 里 `Implicit Iterators - Basic Integer Interpolation` 的 data 就是裸整数 `85`（[designs/02-architecture.md §6.3](../designs/02-architecture.md)）。因此：

- **`render/1` 的入参类型是 `term()` 而非 `map()`**，栈初始化为 `[Ctx]` 即可。生成模块的 `render/1` spec、门面 `ai_mustache:render/2` 的 spec（[T15](T15.md)）都要写成 `term()`。
- `find_frame/2` 遇到非 map frame 跳过（上面已保证）。
- `lookup(['.'], [85])` 必须返回 `85`。

不要给 `render/1` 加 `when is_map(Ctx)` 守卫，dialyzer spec 也不能写 `map()` —— 这会让上述 spec 用例直接失败。

### 3. `truthy/1` —— falsy 定义

[designs/03-semantics.md §2.1](../designs/03-semantics.md)：falsy 恰好是五个值。

```erlang
-spec truthy(term()) -> boolean().
truthy(undefined) -> false;
truthy(false)     -> false;
truthy([])        -> false;
truthy(<<>>)      -> false;
truthy(null)      -> false;
truthy(_)         -> true.
```

要点：

- **`0` 是 truthy**，`0.0` 是 truthy，`#{}` 是 truthy。与标准 mustache 一致，是常见踩坑点，README 中要显式说明（阶段 6）。
- `null` 是 atom `null`，来自 JSON 解码（OTP 的 `json:decode/1` 把 JSON `null` 解成 atom `null`）。
- 五个子句要写成**独立子句**而非 `lists:member/2` 或 `case`，让 BEAM 生成跳转表。
- `truthy/1` 主要给 `{{^x}}`、`{{+x}}`、`{{-x}}` 和 `section/4` 的兜底分支用；`{{#x}}` 的主路径在生成代码里已经把 case 分支全部展开（[designs/04-codegen.md §4](../designs/04-codegen.md) 关键点 5），不走 `truthy/1`。

### 4. `to_binary/1` —— 值 → binary

```erlang
-spec to_binary(term()) -> binary().
to_binary(B) when is_binary(B)   -> B;
to_binary(I) when is_integer(I)  -> integer_to_binary(I);
to_binary(F) when is_float(F)    -> float_to_binary(F, [short]);
to_binary(undefined)             -> <<>>;
to_binary(null)                  -> <<>>;
to_binary(A) when is_atom(A)     -> atom_to_binary(A, utf8);
to_binary(L) when is_list(L)     -> unicode:characters_to_binary(L);
to_binary(T)                     -> ... .
```

**关键点**：

- **`float_to_binary(F, [short])`** —— OTP 24+ 引入、本项目基线 OTP 28 可用。它产出 `<<"1.21">>` 而非默认的 `<<"1.21000000000000000000e+00">>`。spec 的 `interpolation.json` 的 `Basic Decimal Interpolation` 要求 `1.21` → `"1.21"`，`sections.json` 的 `Implicit Iterator - Decimal` 要求 `1.1` → `"1.1"`（[designs/02-architecture.md §6.2](../designs/02-architecture.md)）。**不加 `[short]` 这两个 spec case 必挂**。
- `undefined` / `null` → `<<>>`（缺失变量渲染成空串，是 mustache 的标准行为）。这两个子句必须排在 `is_atom/1` 之前。
- iolist：`unicode:characters_to_binary/1` 可能返回 `{error, _, _}` 或 `{incomplete, _, _}`，要处理 —— 返回错误时降级为 `iolist_to_binary/1`，再失败则走兜底。
- 兜底 `to_binary(T)`：**不要用 `io_lib:format("~p", [T])`** 静默吞掉类型错误。建议 `error({ai_mustache, {not_renderable, T}})`，让模板里塞了 pid / ref / fun 这类值时立刻暴露。是否兜底成空串是一个行为决策，实现时二选一并在模块注释中写明。
- `true` / `false` 走 `is_atom/1` → `<<"true">>` / `<<"false">>`。注意 `{{x}}` 中 `x` 为 `true` 时输出 `"true"`，而 `{{#x}}` 中 `x` 为 `true` 时执行 body 不压栈 —— 两条路径不同，不要混淆。

### 5. 性能约束

- `lookup/2` 在热路径上，栈深度通常 ≤ 5，用尾递归即可，**不要**引入 `lists:foldl/3` 或构造中间列表。
- 三个函数都不得分配不必要的中间数据；`to_binary/1` 对 binary 入参必须**原样返回**（零拷贝）。
- 全模块无进程、无 ets、无 `persistent_term`、无 `erlang:put/2`（[架构不变量 #1](../designs/02-architecture.md)）。

## 验收标准

- [ ] `lookup/2`、`to_binary/1`、`truthy/1` 导出，模块只依赖 OTP（`rebar3 xref` 确认，源码 grep 不到 `ai_maps` / `ai_string` / `ai_function`）
- [ ] `lookup(['.'], [85])` 返回 `85`；`lookup([x], 85)` 形态的裸值根 context 不 crash（B5 的运行期修复）
- [ ] `lookup([a], [#{b => 1}, #{a => 2}])` 返回 `2`（回溯生效）
- [ ] `lookup([a, b], [#{a => #{c => 1}}, #{b => 2}])` 返回 `undefined`（后续段不回溯）
- [ ] `lookup([a], [<<"x">>, #{a => 1}])` 返回 `1`（非 map frame 跳过而非 crash）
- [ ] `lookup([a], [])` 与 `lookup([a], [#{}])` 均返回 `undefined`
- [ ] `truthy/1` 对 `undefined` / `false` / `[]` / `<<>>` / `null` 返回 `false`，对 `0` / `0.0` / `#{}` / `<<"a">>` 返回 `true`
- [ ] `to_binary(1.21)` 精确等于 `<<"1.21">>`，`to_binary(1.1)` 等于 `<<"1.1">>`
- [ ] `to_binary(85)` 等于 `<<"85">>`，`to_binary(undefined)` 与 `to_binary(null)` 等于 `<<>>`
- [ ] `to_binary(<<"x">>)` 返回同一个 binary（`erts_debug:same/2` 或至少不做拷贝）
- [ ] 模块无进程、无 ets、无 persistent_term、无进程字典
- [ ] `rebar3 dialyzer` 全绿，`render/1` 相关 spec 的 Ctx 类型为 `term()` 不是 `map()`
