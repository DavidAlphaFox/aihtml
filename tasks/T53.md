# T53 · ai_jinja_transform

- **阶段**：13
- **依赖**：[T50](T50.md) · [T52](T52.md)
- **状态**：已完成

## 目标

实现 Jinja 的 parse_transform 三形态，结构与 `ai_mustache_transform` 一致，并保证两个 transform 可在同一模块共存。

## 交付物

- `src/ai_jinja_transform.erl`
- `test/ai_jinja_transform_tests.erl`

## 实现要点

### 1. 三形态

| 形态 | 写法 | 无 transform 时 |
|---|---|---|
| (a) 扩展声明 | `-jinja_ext(my_filters).` | 丢失编译期校验 |
| (b) 内联模板 | `ai_jinja:inline(~"Hi {{ n }}", Ctx)` | 降级为运行期编译，输出相同 |
| (c) 文件模板 | `-jinja_template({page, "views/page.j2"}).` | **编译报错**（函数不存在） |

### 2. 三 pass

`collect` → `expand` → `inject`，与 `ai_mustache_transform` 逐段对应。
**三个 pass 全部跑完再决定返回值**，一次编译报出全部错误。

`#st{}` 的 `file` 必须动态跟踪（include 展开后有多个 `-file` attribute），
因此 pass 1 用 `foldl`、pass 2 用 `mapfoldl`。这条直接抄 mustache 侧。

### 3. 形态 (a) 的编译期校验

读 `Mod:filters/0` 与 `Mod:tests/0`，与内置表比对，冲突报错。
模块尚未编译时走 `ai_jinja_ext:spec_module/1` 的静态扫描（[T44](T44.md) §4）。

### 4. 形态 (b) 与运行期回退的一致性

**最重要的一条**（[T50](T50.md) §5）：两条路径必须同样地拒绝同样的东西。
调用 [T50](T50.md) 抽出的共享谓词。

第一参数非字面量时**不展开并 warning**（与 mustache 一致）。

### 5. 形态 (c)

编译模板文件成 `Name/1` 与 `Name_iolist/1` 并导出。
attribute **保留**在 beam 里（plugin 的反向依赖扫描要读它），
与 mustache 侧的 `-mustache_template` 处理一致。

路径解析走 `ai_html_path:resolve/2`，搜索顺序：`.erl` 所在目录 →
`jinja_opts` 的 `views` → 每个 `{i, Dir}` → cwd。
**必须与 plugin 的解析顺序完全一致**，否则 plugin touch 一个文件而
transform 读另一个，反向依赖静默失效。

### 6. 与 mustache transform 共存

[12 §2.1](../designs/12-jinja-toolchain.md)：同一模块可同时声明两个 transform。
互不认识对方的 attribute，各自只消费自己的。

**不得假设自己是第一个或最后一个 transform**：
`module_of/1` 遍历查找 `-module` 而非取 `hd(Forms)`。

### 7. 错误上报

`{error, [{File, [{Line, ?MODULE, Reason}]}], Warnings}`，按 File 分组。
模板内的错误用**模板路径与模板行号**，让编辑器能跳到 `.j2` 的出错行。

`format_error/1` 覆盖 [11 §9](../designs/11-jinja-codegen.md) 的全部 Reason
加上 transform 自己的（`{bad_jinja_template, Term}`、
`{template_not_found, Path, SearchedDirs}` 等）。
`template_not_found` 的文案**必须列出实际搜过的目录**。

## 验收标准

- [ ] 三形态各自可用，且 [T50](T50.md) 的一致性用例在此端到端复现
- [ ] 无任何 jinja attribute / inline 调用的模块经 transform 后 forms 逐字节等价
- [ ] 一次编译报出全部错误
- [ ] 诊断按 File 分组；include 文件里的 attribute 报出该 include 的路径
- [ ] 模板内错误的 File 是 `.j2` 路径、Line 是模板行号
- [ ] 形态 (b) 第一参数非字面量时 warning 且不展开，运行期仍正确
- [ ] 形态 (c) 的 attribute 保留在 beam 里
- [ ] 路径解析顺序与 plugin 完全一致（共享 `ai_html_path`，有断言）
- [ ] 与 `ai_mustache_transform` 共存（两种声明顺序各一条用例）
- [ ] 同一模块混用 `-mustache_template` 与 `-jinja_template` 正确
- [ ] 对同一 forms 连跑两遍 transform 结果相同
- [ ] transform 不含任何 AST → forms 逻辑，全部委托 `ai_jinja_compiler`
- [ ] `format_error/1` 覆盖全部 Reason
