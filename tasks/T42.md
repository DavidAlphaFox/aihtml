# T42 · autoescape 与 safe 传播

- **阶段**：11
- **依赖**：[T41](T41.md)
- **状态**：已完成

## 目标

落地 `{safe, IoData}` 标记与它在内置 filter 中的传播规则。**这是本轮唯一的安全相关任务，搞错一条就是一个 XSS。**

## 交付物

- `src/ai_jinja_rt.erl` —— 新增 `escape/1` · `to_binary/1` · `safe/1` · `unsafe/1`
- `test/ai_jinja_escape_tests.erl`

## 实现要点

### 1. 表示

```erlang
escape({safe, D}) -> D;
escape(V)         -> ai_html_escape:escape(to_binary(V)).

to_binary({safe, D}) -> erlang:iolist_to_binary(D);
to_binary(V)         -> ai_html_escape:to_binary(V).    % 异常标签重包成 ai_jinja
```

`{safe, IoData}` 里放 iodata 而非 binary：`{% filter %}` 块与 `{% set %}` 块
产出的是 iolist，多一次 `iolist_to_binary/1` 是纯浪费。

### 2. compiler 侧

`{escape, true}`（默认）→ `{{ e }}` 编译成 `ai_jinja_rt:escape(E)`；
`{escape, false}` → `ai_jinja_rt:to_binary(E)`。
**编译期常量，无块级 `{% autoescape %}`**（[10 §4.1](../designs/10-jinja-semantics.md)）。

### 3. 传播分类表

[10 §4.2](../designs/10-jinja-semantics.md) 的三类，**每个内置 filter 都必须归类**，
并在 `ai_jinja_filters` 的每个函数上用统一注释标注：

```erlang
%% @safe transparent   —— 输入 safe 则输出 safe
%% @safe escaping      —— 非 safe 输入先转义，输出 safe
%% @safe generating    —— 无条件输出 safe
%% @safe none          —— 不产出字符串（数值/序列 filter）
```

写一条**元测试**：扫描 `ai_jinja_filters` 的源码，断言每个导出的 filter 函数
都有 `@safe` 标注，且标注值在四种之内。漏标一个就是一个待发现的 XSS。

### 4. `{% filter %}` 与 `{% set %}` 块

块体是**已渲染并已转义**的输出，传给 filter 前必须包成 `{safe, Iolist}`，
否则会二次转义成 `&amp;amp;`（[10 §4.3](../designs/10-jinja-semantics.md)）。
两个专项用例。

### 5. `|safe` 与 `|escape` 与 `|forceescape`

- `safe(V)` → `{safe, to_binary(V)}`
- `escape(V)` / `e(V)` → `{safe, ai_html_escape:escape(to_binary(V))}`（已 safe 则原样）
- `forceescape(V)` → 无条件转义，**即使已 safe**

`forceescape` 存在的意义就是打破传播，要有用例证明它与 `escape` 行为不同。

### 6. 转义字符集

复用 `ai_html_escape:escape/1`：`& < > " '` 五个，`'` 输出 `&#39;`。
与 mustache 侧完全一致，不重新实现。

## 验收标准

- [ ] `escape/1` 对 `{safe, _}` 原样输出，对其它值转义
- [ ] `{escape, false}` 时输出不转义（有 fixture）
- [ ] 元测试：`ai_jinja_filters` 每个导出 filter 都有合法的 `@safe` 标注
- [ ] 三类传播各有至少 5 条 fixture，覆盖 safe 与非 safe 两种输入
- [ ] `{% filter upper %}a & b{% endfilter %}` 输出 `A &AMP; B` 而非 `A &AMP;AMP; B`（二次转义回归用例）
- [ ] `{% set x %}a & b{% endset %}{{ x }}` 不二次转义
- [ ] `|forceescape` 对已 safe 的值仍然转义
- [ ] 转义字符集与 mustache 侧一致（同一份实现，有断言）
- [ ] fixture 中 `escape` 组用例全部点亮
