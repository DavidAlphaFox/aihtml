# T01 · rebar3 构建骨架与零依赖 app 定义

- **阶段**：1
- **依赖**：无
- **状态**：已完成

## 目标

把 aihtml 从 erlang.mk 主构建切换到 rebar3，并落实决策 D5：运行期与测试期均零依赖，只依赖 OTP。

## 交付物

- `rebar.config` —— 主构建配置，零 deps，含 test profile、dialyzer、xref
- `src/aihtml.app.src` —— library application 定义，无 `mod` 项
- `.gitignore` —— 增补 `_gen/`、`_build/`、CT 产物
- `Makefile` —— 降级说明，erlang.mk 不再是主构建路径

## 实现要点

### rebar.config

```erlang
{erl_opts, [debug_info,
            warn_export_vars, warn_shadow_vars, warn_obsolete_guard,
            warn_missing_spec, warnings_as_errors]}.

{deps, []}.                                   %% 零依赖，见 designs/02 第 6 节

{profiles, [
    {test, [{deps, []},                       %% spec 用 OTP 自带 json 模块解析
            {erl_opts, [nowarn_export_all, nowarn_missing_spec,
                        {d, 'TEST'}]}]}
]}.

{dialyzer, [{warnings, [unknown, no_improper_lists]},
            {plt_extra_apps, [compiler, syntax_tools]}]}.

{xref_checks, [undefined_function_calls, undefined_functions,
               locals_not_used, deprecated_function_calls]}.

{ct_opts, [{keep_logs, 10}]}.
```

- `warnings_as_errors` 从一开始就打开，避免后期积累。
- `plt_extra_apps` 要含 `compiler` 和 `syntax_tools`：`ai_mustache_compiler` 会用到 `erl_syntax` / `erl_prettypr` / `compile`。
- 暂不引入 `rebar3_lint` / `rebar3_ex_doc` 等 project_plugins，保持依赖面最小；需要时在 T29 再加。

### src/aihtml.app.src

```erlang
{application, aihtml,
 [{description, "Mustache template engine that compiles templates to Erlang modules"},
  {vsn, "0.4.0-dev"},
  {registered, []},
  {applications, [kernel, stdlib]},
  {env, []},
  {modules, []},
  {licenses, ["MIT"]},
  {links, [{"GitHub", "https://github.com/DavidAlphaFox/aihtml"}]}
 ]}.
```

- **无 `mod` 项** —— 这是 library application，不启动任何进程（designs/02 第 2.4 节）。
- `applications` 只列 `kernel` 和 `stdlib`，不含 `crypto`（旧 `aihtml_app:start/2` 里启动 crypto 和 ailib 的代码随 T02 一起移出）。
- 版本先标 `0.4.0-dev`，T29 发布时去掉 `-dev`。

### .gitignore

在现有内容基础上增补：

```
_gen/
_build/
rebar3.crashdump
ct_logs/
```

现有的 `.rebar3`、`_build`、`ebin`、`logs` 等条目已存在，只补缺失项，不要重排。

### Makefile

保留 erlang.mk 构建能力但降级：在文件顶部加注释说明 rebar3 是主构建路径，erlang.mk 仅作兼容保留，并去掉 `DEPS = ailib` 与 `dep_ailib` 两行（决策 D5）。

## 验收标准

- [ ] `rebar3 compile` 成功且无 warning
- [ ] `rebar3 as test compile` 成功
- [ ] `rebar.config` 的 `deps` 与 test profile 的 `deps` 均为空列表
- [ ] `src/aihtml.app.src` 不含 `mod` 项
- [ ] `grep -r ailib rebar.config Makefile src/` 无结果
- [ ] `.gitignore` 含 `_gen/`
