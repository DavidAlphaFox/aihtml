# T31 · ai_html_forms 抽取

- **阶段**：7
- **依赖**：无
- **状态**：已完成

## 目标

把 `ai_mustache_compiler` 中与模板语言无关的 Erlang abstract forms 构造器抽成共享模块 `ai_html_forms`，供两个引擎共用。**纯机械抽取，不得夹带任何逻辑改动。**

## 交付物

- `src/ai_html_forms.erl`
- `src/ai_mustache_compiler.erl` —— 改为调用共享模块，删除被抽走的私有函数
- `test/ai_html_forms_tests.erl`

## 实现要点

### 1. 抽取清单

从 `ai_mustache_compiler` 的「Form constructors」小节整体搬运：

`a/2` `v/2` `n/2` `cl/4` `bin/2` `empty_bin/1` `concat_bin/3` `mklist/2`
`rem_call/4` `loc_call/3` `g/3` `fn/4` `spec/4` `t/2` `param/3` `uses_var/2`
`anno/1` `remotes/2`

以及 `static_text/1` 依赖的 `literal_of/1` 与 `is_literal_or_indent/1` —— 后两者
虽然被常量折叠使用，但判断的是「这个 abstract expr 是不是字面量」，与模板语言无关，
Jinja 的常量折叠需要同一份实现。

**不抽**：`keys/2`（key 路径是 mustache 概念）、`rt/3`（写死了 `ai_mustache_rt`）、
`hd_stack/1`（context stack 是 mustache 概念）、`line/2`（读 `#cs{}`）。

`rt/3` 的通用形式已经是 `rem_call/4`，两个引擎各自定义自己的一行包装即可。

### 2. 两个必须保留原样的实现细节

`bin/2` 里有两条踩过坑的规则，抽取后要把注释一并搬过去并加强：

- `{string, _, Chars}` 的 bin_element 类型必须是 **default**，不是 `[binary]`；
- 非 ASCII 文本必须以 `[utf8]` 类型的字符发出，不能是裸字节。

这两条在共享模块里的价值比在 mustache 里更大 —— Jinja 引擎会无条件继承。

### 3. `param/3` 的语义要写清楚

`param(L, Name, Body)`：Body 里没用到 Name 时返回 `_Name`。
存在的理由是生成模块要过 `warnings_as_errors`。这条注释必须搬。

### 4. 依赖方向

`ai_html_forms` **只依赖 OTP**，不得引用任何 `ai_mustache_*` / `ai_jinja_*`
（[08 §5](../designs/08-jinja-architecture.md) 不变量 10）。`rebar3 xref` 可验证。
