# 没有「追加文本」的 op，流式文本只能逐块 `html(…, append)`

报的人：beamai_muse　严重度：🟡　回没回：✅ 已实现

## 症状

能用，但费：LLM 的流式输出（每 50–100 ms 一块）只能写成

```erlang
aihtml_push:publish(Topic, fun(C) -> aihtml_action:html(C, {id, Bubble}, Delta, append) end)
```

每一块在浏览器里都走 `insertAdjacentHTML` → settle class → 挂载扫描，只是为了往一个
`<span>` 里加几个字。

## 位置

`apps/aihtml/src/aihtml_action.erl:53-55` —— 导出的 op 里只有 `html/3,4`
（`inner | outer | append | prepend | morph | morph_inner`），没有只改文本的 op。

## 怎么撞上的

beamai_muse 聊天页：`TEXT_MESSAGE_CONTENT` 增量经服务端中继推到页面，逐块追加到
回复气泡里，结束时再整体 morph 成 `ah_markdown_view`。

## 影响面

所有做流式文本（聊天、日志尾随、进度输出）的页面。不报错，只是每块多做了不必要的
DOM 解析和扫描；长回复时能看出来。

## 建议

- 新 op：`{op: "text", target, value, mode: append | replace}`，浏览器侧用
  `textContent` / `Text.appendData`；Erlang 侧 `aihtml_action:text/3,4`；
- 可选：`markdown_view` 组件加一个 `appendMarkdown` 方法（客户端增量渲染，或由服务端
  定时 morph）。
